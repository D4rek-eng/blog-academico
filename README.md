# Cuaderno

Blog académico responsive creado con React, TypeScript y Vite.

## Desarrollo

Instala las dependencias con `npm install` y ejecuta `npm run dev`. Para compilar, utiliza `npm run build`.

## Funciones

- Publicaciones cronológicas con búsqueda, categorías y etiquetas.
- Editor para crear y editar entradas, con carga de portada local (JPG, PNG o WEBP, hasta 4 MB).
- Comentarios publicados desde la vista de cada artículo.
- Enlaces permanentes y descarga del feed RSS.
- Persistencia local de entradas y comentarios mediante `localStorage`.
- Vistas de archivo, proyecto y administración, además de diseño adaptable a móvil.

Los datos se guardan en el navegador actual; no hay un servidor compartido ni cuentas de usuario.
